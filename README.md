**Project Title**- Tick-Tack-Toe

**Team Members**- Harshita Gahlot(26CSU006), Medha Gupta(26CSU016), Anshika Rana(26CSU021), Ashi Jain(26CSU035)

**Description**- Tic-Tac-Toe is a two-player, turn-based game played on a 3 × 3 board. Players take turns entering a position from 1
to 9; Player 1 uses X and Player 2 uses O. The program checks after every move whether a player has completed a
row, column or diagonal. If all nine positions are filled without a winner, the game ends in a draw.
